Conocé la pulsera

Componentes principales de la propuesta NexoBand.

🚨

Botón SOS

Permite generar una alerta de emergencia de manera directa.

📡

Comunicación inalámbrica

Permite transmitir la alerta hacia el sistema de recepción.

🧠

ESP32-C3

Actúa como unidad de control para gestionar las funciones electrónicas.

🌀

MPU6050

Sensor de movimiento utilizado para detectar cambios y eventos asociados.

🔋

Batería recargable

Alimenta el dispositivo para permitir su funcionamiento portátil.

💡

Indicadores LED

Brindan una señal visual del estado del dispositivo.

Evolución del proyecto

Futuras mejoras

Ideas para llevar NexoBand desde el prototipo hacia una solución cada vez más completa.

📡
01 · CONECTIVIDAD

Mayor alcance

Ampliar la distancia de comunicación para cubrir espacios más grandes y mejorar la recepción de alertas.

🧠
02 · SENSORES

Nuevas funciones

Incorporar nuevos sensores para detectar más situaciones y obtener información adicional.

⌚
03 · DISEÑO

Más compacta y cómoda

Reducir tamaño y mejorar la ergonomía para que la pulsera resulte más cómoda durante su uso.

🔋
04 · AUTONOMÍA

Mayor duración

Optimizar el consumo energético para extender el tiempo de funcionamiento entre cargas.

⚙️
05 · SISTEMA

Más herramientas para responder

Ampliar las funciones del sistema y mejorar la información disponible para quienes reciben y gestionan una alerta.

El proyecto

NexoBand nace como una propuesta de 7.º 2.ª · Informática de la E.E.S. Técnica N.º 3 Del Viso, combinando electrónica, programación y comunicación para pensar nuevas formas de asistencia en emergencias.
